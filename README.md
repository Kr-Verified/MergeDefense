# Merge Defense

동일한 레벨의 포탑을 합성해 더 강한 포탑으로 키우고, 몰려오는 적으로부터 성을 지키는 웹 기반 머지 디펜스 게임입니다. 별 등급, 속성, 장비, 스킬, 업그레이드를 조합해 최대한 오래 생존하는 것이 목표입니다.

https://mergedefense.netlify.app/

## 주요 특징

- **드래그 앤 드롭 머지**: 같은 레벨의 포탑 두 개를 겹치면 한 단계 높은 포탑으로 합성됩니다.
- **랜덤 성장 요소**: 포탑은 생성될 때 별 등급과 속성을 확률적으로 얻고, 적도 생존 시간에 따라 속성을 획득합니다.
- **전략적인 배치**: 포탑을 보드에 배치하면 자동으로 적을 공격하고, 다시 하단 보관함으로 회수할 수 있습니다.
- **개별/전체 업그레이드**: 포탑별 공격 속도, 공격력, 사거리를 강화하거나 전체 포탑 능력치를 올릴 수 있습니다.
- **장비 시스템**: 적 처치 시 드랍되는 장비를 장착하거나 같은 장비끼리 합성해 효과를 키울 수 있습니다.
- **속성 구슬 & 대장간**: 대기 중인 포탑을 분해해 속성 구슬을 얻고, 대장간에서 구슬 3개씩 조합해 새로운 속성을 만들 수 있습니다. 포탑을 합성할 때마다 조합서를 얻을 확률도 있습니다.
- **액티브 스킬**: 포격, 빙결파, 골드러시, 응급 수리로 위기 상황을 돌파할 수 있습니다.
- **팀 플레이(방 시스템)**: 초대코드와 선택적 비밀번호로 방을 만들고 참가해, 골드를 제외한 포탑/업그레이드/성 체력/적 웨이브를 함께 공유하는 협동 모드를 즐길 수 있습니다. 팀원의 마우스 위치도 화면에 실시간으로 표시됩니다.
- **랭킹 지원**: Supabase 설정 시 생존 시간이 랭킹에 저장되고 시작 화면에서 확인됩니다.

## 게임 방법

1. 시작 화면에서 닉네임을 입력하고 `start`를 누릅니다.
2. 하단의 `생성` 버튼으로 포탑을 만듭니다. 생성 비용은 현재 생성 레벨에 따라 증가합니다.
3. 같은 레벨의 포탑을 드래그해 겹치면 더 높은 레벨의 포탑으로 합성됩니다.
4. 포탑을 상단 보드로 드래그하면 설치됩니다. 설치된 포탑은 사거리 안의 적을 자동 공격합니다.
5. 설치된 포탑을 클릭하면 업그레이드, 타게팅 우선순위, 장비 장착을 관리할 수 있습니다.
6. 적이 성에 도달하면 성 체력이 감소합니다. 성 체력이 0이 되면 게임이 종료됩니다.

## 핵심 시스템

### 포탑

포탑은 레벨, 별 등급, 속성, 장비, 업그레이드 상태를 가집니다.

- 별 등급은 1성부터 5성까지 있으며, 높은 별일수록 공격력과 체력이 크게 증가합니다.
- 생성 시 기본 확률로 1~4성이 등장하고, 5성은 타임 재화를 사용한 성급 업그레이드로 도달합니다.
- 머지할 때 두 재료 중 더 높은 별 등급이 결과 포탑에 계승됩니다.
- 설치된 포탑은 시간이 지날수록 `타임`을 얻고, 적 처치 시 추가 타임을 얻습니다.
- 타임은 포탑 개별 업그레이드와 성급 업그레이드에 사용할 수 있습니다.

### 속성

포탑은 일정 확률로 특수 속성을 얻습니다.

| 속성 | 효과 |
| --- | --- |
| 물 | 적을 3초 동안 둔화시킵니다. |
| 불 | 3초 동안 지속 피해를 줍니다. |
| 폭탄 | 대상 주변 적에게 범위 피해를 줍니다. |
| 공 | 공격 속도가 빨라지지만, 적을 3성으로 강화시킬 위험이 있습니다. |
| 힘 | 공격력이 증가합니다. |
| 벽 | 공격 속도는 느려지지만 적을 정지시킵니다. |
| 피 | 공격력은 낮아지지만 준 피해 일부만큼 성 체력을 회복합니다. |

머지 시 `공` 속성이 가장 우선 계승됩니다. 그 외에는 속성이 있는 포탑의 속성이 이어지고, 둘 다 속성이 있으면 드래그한 포탑의 속성이 우선됩니다.

### 적

적은 오른쪽에서 등장해 왼쪽 성을 향해 이동합니다.

- 시간이 지날수록 등장 가능한 적 레벨이 높아집니다.
- 4의 배수 레벨 적은 더 빠르게 이동합니다.
- 5의 배수 레벨 적은 보스이며 체력이 높고 자연 회복합니다.
- 3의 배수 레벨 적은 근처 포탑을 공격할 수 있습니다.
- 보스는 주변 포탑에 광역 피해와 기절을 줄 수 있습니다.
- 생존 시간이 길어질수록 적에게 무작위 속성이 붙을 확률이 높아집니다.
- 적 처치 시 골드를 얻고, 일정 확률로 장비가 드랍됩니다.

#### 적 속성 등장 확률

| 생존 시간 | 무속성 | 속성 |
| --- | ---: | ---: |
| 0~29초 | 100% | 0% |
| 30~99초 | 80% | 20% |
| 100~599초 | 60% | 40% |
| 600초 이후 | 5% | 95% |

30초 이후에는 `공중`, `고스트`, `골렘`, `번개`가 균일 확률로 등장합니다. 100초 이후에는 `재생`, `방패`, `분열`, `암살자`, `중갑`, `마법저항`이 추가됩니다. 600초 이후에는 모든 적 속성이 균일 확률로 등장합니다.

#### 적 속성 효과

| 적 속성 | 효과 |
| --- | --- |
| 공중 | 일반 지상 공격 피해를 크게 줄이고, 공/번개 계열 대응 속성에 더 큰 피해를 받습니다. |
| 고스트 | 일반 공격을 일정 확률로 회피하며, 벽 계열 정지 공격에 약합니다. |
| 골렘 | 체력이 높고 이동이 느리며 둔화/정지 효과를 덜 받습니다. 힘/폭탄 계열 피해에 약합니다. |
| 번개 | 이동 속도가 빠르고 일정 주기마다 짧게 순간이동합니다. 물/벽 계열에 약합니다. |
| 얼음 | 둔화와 정지 효과를 크게 줄입니다. 불 계열 피해에 약합니다. |
| 화염 | 지속 피해를 덜 받습니다. 물 계열에 약합니다. |
| 재생 | 시간이 지나면 체력을 회복합니다. 불 지속 피해나 폭탄 피해에 약합니다. |
| 방패 | 앞에서 받는 일반 피해를 줄입니다. 폭탄 범위 피해나 뒤쪽 공격에 약합니다. |
| 분열 | 죽으면 작은 무속성 적으로 나뉩니다. 폭탄 피해로 처치하면 분열하지 않고 더 큰 피해를 받습니다. |
| 광폭 | 체력이 낮아지면 이동 속도가 빨라집니다. 벽/물 계열 제어가 중요합니다. |
| 흡혈 | 성에 닿으면 성 피해량이 높고 자신의 체력을 회복합니다. 힘/폭탄 계열에 약합니다. |
| 마법저항 | 불, 물, 피 같은 특수 속성 피해를 덜 받습니다. 힘/공 계열 기본 피해에 약합니다. |
| 중갑 | 일반 공격 피해를 줄입니다. 지속 피해와 폭탄 피해에 약합니다. |
| 암살자 | 매우 빠르고 성 피해가 높지만 체력이 낮습니다. |
| 보스 | 5의 배수 레벨 적에게 붙는 별도 특성입니다. 자연 회복하고 상태이상 시간이 짧게 적용됩니다. |

### 장비

장비는 하단 보관함의 `아이템` 탭에서 확인할 수 있습니다. 설치된 포탑을 클릭한 뒤 장비 슬롯으로 드래그하면 장착됩니다.

| 장비 | 효과 |
| --- | --- |
| 기름 | 공격 속도 증가 |
| 조준경 | 공격 범위 증가 |
| 화약 | 공격력 증가 |
| 무게추 | 폭탄 범위 증가 |
| 바늘 | 치명타 확률 증가 |
| 망치 | 치명타 피해 증가 |
| 방패 | 최대 체력 증가 |

같은 종류의 장비끼리는 드래그 앤 드롭으로 합성할 수 있습니다. 두 장비의 수치를 기준으로 더 강한 장비가 생성됩니다.

### 대기 포탑 관리

하단 보관함에서 아직 설치하지 않은(대기 중인) 포탑을 클릭하면 작은 메뉴가 뜹니다.

| 동작 | 설명 |
| --- | --- |
| 삭제 | 포탑 레벨의 제곱(`lv²`)만큼 골드를 소모해 포탑을 없앱니다. 골드가 부족하면 버튼이 비활성화됩니다. |
| 분해 | 포탑을 없애고 그 포탑의 속성을 속성 구슬 1개로 바꿉니다. 속성이 없는 포탑은 분해할 수 없습니다. |
| 융합 | 보유한 속성 구슬 하나를 소모해 그 포탑의 속성을 바꿉니다. |
| 취소 | 메뉴를 닫습니다. |

### 속성 구슬과 대장간

포탑을 분해하면 속성 구슬을 얻습니다. 하단 탭의 `대장장` 버튼을 누르면 대장간 창이 뜨고, 동시에 보관함이 보유 중인 조합서 목록으로 전환됩니다.

대장간에서는 구슬 3개를 골라 새로운 속성 구슬을 합성할 수 있습니다. 정해진 조합표에 있는 정확한 3개 조합일 때만 결과가 표시되며, 표에 없는 조합은 합성 버튼이 비활성화된 채 아무 결과도 나오지 않습니다.

- **1단계**: 기존 7개 기본 속성(물/불/폭탄/공/힘/벽/피)을 분해로 얻습니다.
- **2단계**: 기본 속성 3개를 조합(같은 속성 3개 또는 서로 다른 속성 3개, 총 41종)해 새로운 속성 구슬을 만듭니다. (예: 물 + 물 + 물 → 빙결)
- **3단계**: 2단계 구슬(또는 3단계 구슬끼리)을 3개 조합해 20종의 최종 속성 구슬을 만듭니다. (예: 빙결 + 화산 + 대포 → 빙화산포)

각 속성 구슬은 이름과 효과 설명이 함께 표시되지만, 실제 전투 효과는 아직 구현되지 않은 설계 단계입니다.

### 조합서

같은 레벨의 포탑을 합성할 때마다 20% 확률로 조합서를 하나 얻습니다. 대장간의 61개 레시피 중 하나가 무작위로 발급되며, 어떤 조합인지와 효과 설명을 미리 확인할 수 있는 수집형 아이템입니다. 이미 가지고 있는 조합서를 다시 얻으면 중복 없이 그냥 사라집니다. 조합서는 하단 보관함의 `대장장` 탭에서 확인할 수 있습니다.

### 스킬

보드 왼쪽의 스킬 버튼으로 전투를 보조할 수 있습니다.

| 스킬 | 효과 | 쿨다운 |
| --- | --- | --- |
| 포격 | 모든 적에게 현재 최대 체력의 30%만큼 피해를 줍니다. | 20초 |
| 빙결파 | 모든 적을 4초 동안 둔화시킵니다. | 15초 |
| 골드러시 | 즉시 골드를 획득합니다. (`max(20, floor(40 × 생성레벨^1.5))`) | 25초 |
| 응급 수리 | 성 체력을 최대 체력의 20%, 설치된 모든 포탑의 체력을 각 포탑 최대 체력의 20%만큼 회복합니다. | 30초 |

스킬은 각각 쿨다운이 있으며, 배속 상태에 따라 쿨다운 진행도 함께 빨라집니다.

## 업그레이드

- **생성 단계 향상**: 새로 생성되는 포탑의 기본 레벨을 올립니다.
- **개별 업그레이드**: 설치된 포탑의 공격 속도, 공격력, 사거리를 올립니다.
- **전체 업그레이드**: 모든 포탑의 공격 속도, 공격력, 사거리를 올립니다.
- **치명타 업그레이드**: 치명타 확률과 치명타 피해량을 강화합니다.
- **성 체력 향상**: 성의 최대 체력을 늘리고 즉시 일부 회복합니다.
- **설치 최대치 +1**: 동시에 설치 가능한 포탑 수를 늘립니다.
- **배속**: 1배속, 2배속, 5배속, 0배속(정지)을 전환합니다.

업그레이드 버튼에는 `x1`, `x10`, `x100` 선택 버튼이 붙어 있어 여러 번의 업그레이드를 한 번에 구매할 수 있습니다.

## 팀 플레이 (방 시스템)

시작 화면의 **팀 플레이** 버튼으로 `room.html` 로비에 입장합니다.

- **방 만들기**: 방 이름, 선택적 비밀번호, 최대 인원(2/3/4/6인)을 지정해 방을 만듭니다. 6자리 초대코드가 자동 발급됩니다.
- **참가하기**: 초대코드와 (설정된 경우) 비밀번호를 입력해 참가합니다. 열린 방 목록에서 방을 눌러 코드를 자동으로 채울 수도 있습니다.
- **대기실**: 참가자 목록이 실시간으로 표시됩니다. 호스트만 `게임 시작`, `방 삭제` 버튼을 볼 수 있습니다. 누구나 `나가기`로 방을 떠날 수 있습니다.
- **게임 진행 방식**: 각 플레이어의 **골드만 개인별로 관리**되고, 포탑 배치/포탑 체력/장비/속성 구슬/전역 업그레이드/성 체력/배속/적 웨이브는 방 전체가 공유됩니다. 한 플레이어가 포탑을 만들거나 배치, 업그레이드하면 모든 플레이어 화면에 같은 상태로 반영됩니다.
- **마우스 포인터 공유**: 게임 중 각 플레이어의 마우스 위치가 다른 팀원의 화면에 색이 있는 원과 닉네임으로 실시간 표시됩니다. 업그레이드 창 등 모달이 열려 있으면 항상 포인터보다 위에 표시됩니다.
- **호스트 권한**: 적 스폰, 전투 판정, 성 체력 자연 회복, 보스 자연 회복, 포탑 타임 증가는 호스트 클라이언트가 계산해 나머지 참가자에게 실시간 브로드캐스트합니다. 호스트가 접속을 끊으면 새 적 스폰과 전투 판정이 멈추므로(자동 호스트 이전은 아직 없음), 호스트는 게임 도중 접속을 유지해야 합니다.
- **알려진 한계 (v1)**: 호스트가 자신의 포탑 업그레이드 창을 여는 동안에는 공용 웨이브 스폰과 전투 판정도 함께 일시정지됩니다. 방 비밀번호는 SHA-256 해시로 저장되지만 별도 인증 서버 없이 클라이언트에서 비교하는 방식이라 완전한 보안은 아닙니다. 진행 중인 방에는 중간 참가가 불가능합니다.

## 실행 방법

이 프로젝트는 별도 빌드 과정이 없는 정적 웹 프로젝트입니다.

```bash
python3 -m http.server 8000
```

브라우저에서 아래 주소로 접속합니다.

```text
http://localhost:8000
```

파일을 직접 열어도 동작할 수 있지만, 랭킹 API 요청과 브라우저 보안 정책을 고려하면 로컬 서버 실행을 권장합니다.

## Supabase 랭킹 설정

`js/supabase-config.js`에 Supabase REST API 정보를 입력하면 랭킹 저장과 조회가 활성화됩니다.

```js
window.SUPABASE_CONFIG = {
  url: 'https://YOUR_PROJECT.supabase.co',
  publicKey: 'YOUR_SUPABASE_PUBLISHABLE_KEY',
  rankingsTable: 'rankings'
};
```

필요한 테이블 예시는 다음과 같습니다.

```sql
create table rankings (
  id bigint generated by default as identity primary key,
  name text not null,
  survival_time integer not null,
  created_at timestamptz not null default now()
);
```

Supabase를 설정하지 않으면 게임은 정상 실행되지만 랭킹 저장과 조회는 비활성화됩니다.

## Supabase 팀 플레이(방 시스템) 설정

방 시스템을 사용하려면 Supabase SQL Editor에서 아래 테이블을 추가로 생성해야 합니다. 랭킹 테이블과 마찬가지로 별도 인증 없이 publishable key로 접근하는 구조이므로 RLS는 비활성 상태(기본값)로 둡니다.

```sql
create table rooms (
  id bigint generated by default as identity primary key,
  code text not null unique,
  name text not null,
  password_hash text,
  host_client_id text not null,
  max_players int not null default 4,
  status text not null default 'waiting',
  castle_max_hp numeric not null default 1000,
  castle_hp numeric not null default 1000,
  created_at timestamptz not null default now(),
  updated_at timestamptz not null default now()
);

create table room_players (
  id bigint generated by default as identity primary key,
  room_id bigint not null references rooms(id) on delete cascade,
  client_id text not null,
  name text not null,
  is_host boolean not null default false,
  joined_at timestamptz not null default now(),
  unique (room_id, client_id)
);
```

또한 Supabase 프로젝트의 **Realtime** 기능(Broadcast/Presence)이 활성화되어 있어야 하며, `room-<roomId>`라는 이름의 공개 채널에 대해 별도 Realtime Authorization 정책을 추가하지 않은 기본 설정을 가정합니다. 프로젝트가 비공개 채널(private) 정책으로 전환되어 있다면 `realtime.messages`에 대한 RLS 정책을 추가로 구성해야 합니다.
